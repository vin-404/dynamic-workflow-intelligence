## THE ARCHITECTURE DECISION THAT MAKES A REMEMBER SIMPLE

The browser only ever talks to `vercel.app`. `next.config.ts` proxies `/api/*`
to the Render backend server-side. That is already true and it is why auth is
easy here:

- **Auth.js (NextAuth v5) runs in Next.js**, not in FastAPI. Google OAuth, a
  same-origin session cookie, no cross-origin cookie problems at all.
- **The Next proxy injects identity.** After verifying the session, the rewrite
  adds `X-User-Id` (the user's id) and `X-Proxy-Secret` (a shared secret) to the
  upstream request.
- **The backend trusts `X-User-Id` only when `X-Proxy-Secret` matches.** Without
  it, the header is ignored and the request is anonymous. That stops anyone
  calling `onrender.com` directly and impersonating a user.
- Do NOT implement OAuth in FastAPI. Do NOT put session cookies on the Render
  domain.

## THE VISUAL DIRECTION — THIS IS THE POINT OF WAVE 2

The current UI reads as generated. Fix that mostly by subtraction.

**Remove entirely:** gradients, emoji used as icons, any "AI-powered" or
"✨ Smart" badge, and the uniform card-grid layout where every tile has equal
visual weight.

**Adopt a dense, information-first aesthetic** in the spirit of Linear, Height
or a Vercel dashboard:

- **One primary surface.** The dependency map is the hero. A wide main column
  with a narrow inspector rail beside it. Not three equal columns.
- **Density over air.** Tight rows, small type, a lot of true information per
  screen. Airy card layouts read as brochure; real tools are dense.
- **Typography does the hierarchy, not boxes.** Vary size and weight. Most
  panels need no border and no shadow at all.
- **Tabular numerals everywhere a number appears** (`font-variant-numeric:
  tabular-nums`). This one change makes data look engineered.
- **One accent colour, used sparingly** — reserve it for critical path and
  high-severity findings. Muted neutrals carry everything else. Severity uses
  exactly three states, not a rainbow.
- **Domain vocabulary in the labels**: "slack", "critical path", "zero-slack
  chain", "attributed delay", "must redo". Never "Insights", "Overview",
  "Analytics".
- **Evidence inline.** Task keys, timestamps and the arithmetic belong on the
  row, not hidden behind a click. Dense factual text is what makes it read as a
  real tool.
- **lucide-react** for icons, sparingly, at a single size.
- Dark and light both work. Respect the system preference.

**Specific panels:**
- *Findings* — a tight list: task key, kind, impact, one line of evidence.
  Not a stack of cards.
- *Risk* — the nine factors as a compact bar per factor with the weight beside
  it. That table IS the product; do not hide it behind a single score.
- *Diff* — genuinely side by side: before, after, delta column, tabular
  numerals, changed rows highlighted.
- *Dependency map* — time on the x-axis, resources as lanes, accent for
  zero-slack, one marker line for today.
